# Виджет отзывов «Кенгуру» для Flexbe

Готовая карусель в стиле Apple: крупная активная карточка по центру, соседние карточки видны по краям, прозрачный фон, стеклянные карточки, стрелки, точки, свайп и автоматическое переключение.

## Что уже настроено

- организация Яндекс Карт: `158191390944`;
- прозрачный фон страницы и секции;
- адаптация под компьютер, планшет и телефон;
- автоматическая загрузка свежих отзывов;
- обновление раз в 30 минут;
- автопрокрутка раз в 5,5 секунды;
- перелистывание стрелками, точками, клавиатурой и свайпом;
- демонстрационные карточки до подключения серверной части.

## Запуск на компьютере

```bash
npm install
npx playwright install chromium
npm start
```

Откройте `http://localhost:3000`.

## Размещение

Проект требует Node.js-хостинг, потому что Flexbe и браузер не могут напрямую забирать отзывы из Яндекс Карт. Подойдут Render, Railway или VPS.

Переменные окружения:

- `PORT=3000`
- `CACHE_TTL=1800000`
- `REVIEW_LIMIT=20`
- `YANDEX_ORG_URL=https://yandex.ru/maps/org/kenguru/158191390944/`

## Код для Flexbe

После публикации проекта замените `АДРЕС-ВИДЖЕТА` на полученную ссылку и вставьте код в HTML-элемент Flexbe:

```html
<div style="width:100%;overflow:hidden;background:transparent;">
  <iframe
    src="https://АДРЕС-ВИДЖЕТА"
    title="Отзывы гостей клуба Кенгуру"
    width="100%"
    height="650"
    frameborder="0"
    scrolling="no"
    loading="lazy"
    style="display:block;width:100%;border:0;background:transparent;overflow:hidden;"
    allowtransparency="true">
  </iframe>
</div>
```

Рекомендуемая высота iframe:

- компьютер: `650px`;
- телефон: `540px`.

Если Flexbe позволяет назначить отдельный код для мобильной версии, поставьте там высоту 540 px.

## Важно

Яндекс не предоставляет документированный публичный API для вывода отзывов в полностью произвольном дизайне. Сервер читает публичную страницу организации. Если Яндекс изменит разметку страницы, селекторы в `server.js` может потребоваться обновить.
